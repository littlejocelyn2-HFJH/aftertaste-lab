# 記憶深夜食堂：情感特調製研所

國三「飲食與情感」散文寫作鷹架。學生依四道工序寫作，最後產出一張可截圖／存圖的「情感食譜卡」。

## 檔案
- `index.html`：網頁本體（學生頁、`#scores` 教師後台、`#screen` 大屏）
- `config.js`：填入 Apps Script 網址
- `apps-script/Code.gs`：Google 試算表後端

## 一、開啟 GitHub Pages
1. 到 Settings → Pages，Source 選 **Deploy from a branch**，分支選 **main / (root)**，按 Save。
2. 約 1 分鐘後網址為 `https://littlejocelyn2-hfjh.github.io/<repo 名稱>/`。

## 二、部署 Apps Script（成績蒐集）
1. 建一個新的 Google 試算表 → 擴充功能 → Apps Script。
2. 刪掉原本內容，貼上 `apps-script/Code.gs` 全部程式。
3. **把第 8 行的 `change-me` 改成你的老師密碼**（沒改的話，任何密碼都會被拒絕）。
4. 部署 → 新增部署作業 → 類型選「網頁應用程式」；執行身分：**我**；誰可以存取：**所有人** → 部署並授權。
5. 複製結尾是 `/exec` 的網址，貼進 `config.js` 的引號裡（或交給 Claude 幫你填）。
6. 直接打開該網址看到 `{"ok":true,...}` 是正常的，那是後端。

> 之後如果修改了 Code.gs：重新貼上 → 再改一次第 8 行密碼 → 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不會變。

## 三、老師怎麼看
- 網址後面加 `#scores` 進入教師後台（學生登記視窗下方也有連結）。
- 未登入：只看得到字數榜。
- 登入後：全班情感調色盤、菜單、作品紀錄（可篩座號、只看需留意、點「查看」看整張食譜卡）、複製到 Excel、匯出 CSV、匯入作品碼、清除本班資料、📺 開啟大屏。
- 「需留意」只是提醒：用時少於門檻（預設 180 秒）、字數少於門檻（預設 150 字）、兩段內容重複、連續重複字。門檻可在頁面上調整。
- 試算表會自動出現兩個工作表：`data`（程式用，請勿手動改）與 `作品紀錄`（每次作品一列，可直接篩選）。

## 四、大屏
- 老師登入後按「📺 開啟大屏」（或網址加 `#screen`），投影用；每 15 秒自動更新。
- 只顯示完成人數、全班情感比例、字數前五名、料理名稱，不顯示作品內容與用時。

## 注意事項
- `config.js` 未填網址時為「本機模式」：作品只存在學生自己的裝置。
- 學生網路斷線時，交件畫面會出現「作品碼」，學生複製給老師，老師在教師區匯入即可。
- 照片會縮小後存入試算表（只保留最新一張）；每位學生保留最近 20 次作品。
- 修改後若畫面沒更新，請按 Ctrl+F5 強制重新整理。
